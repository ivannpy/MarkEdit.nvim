1. INTRODUCTION                                                       *markedit*

Requires Neovim 0.11 or newer.

markedit.nvim opens the current Markdown buffer in MarkEdit, writes your edits
to disk as you type and sends the cursor position to the MarkEdit-nvim
extension, which moves MarkEdit's cursor (and so its preview) to the same line.

A small HTTP server listens on a loopback address and pushes Server-Sent
Events to the extension. It only accepts connections that look like they come
from the extension. See docs/protocol.md in the repository for the details.

==============================================================================
2. COMMANDS                                                   *markedit-commands*

                                                                 *:MarkEditOpen*
:MarkEditOpen       Open the current buffer in MarkEdit and follow it. The
                    buffer is written first if it has unsaved changes.

                                                                *:MarkEditClose*
:MarkEditClose      Stop following the current buffer. The server stops when
                    the last buffer is released.

                                                               *:MarkEditToggle*
:MarkEditToggle     Run |:MarkEditOpen| or |:MarkEditClose|.

                                                               *:MarkEditStatus*
:MarkEditStatus     Show the server address, followed buffers and the viewers
                    that are connected.

                                                                  *:MarkEditLog*
:MarkEditLog        Show the plugin log in a scratch buffer, including the
                    diagnostics reported by the extension.

3. CONFIGURATION                                                *markedit-config*

Call `require("markedit").setup({...})`. Options and defaults: >lua

    {
      app = "MarkEdit",
      background = false,
      host = "127.0.0.1",
      port = 47821,
      port_count = 10,
      token = nil,
      allowed_origins = { "http://localhost" },
      filetypes = { "markdown" },
      sync = { cursor = true, debounce = 40 },
      autosave = {
        enabled = true,
        events = { "InsertLeave", "TextChanged" },
        debounce = 300,
      },
      notify = true,
      open = nil,
    }
<
app             macOS application that shows the file.
background      Open it in the background without taking focus from the
                terminal (`open -g`). Default is false: MarkEdit comes to
                the front.
host, port      Address of the bridge. The extension must use the same.
port_count      How many ports to try, starting at `port`. Each Neovim takes
                the first free one, so several can be open at once. The
                extension needs the same `portCount`. 1 means only `port`.
token           Optional shared secret, the extension needs the same value.
allowed_origins Web origins (http/https) allowed to connect. Defaults to
                `{ "http://localhost" }`, the origin MarkEdit's webview
                reports. Setting it replaces the list.
filetypes       Filetypes that can be opened in the viewer.
sync.cursor     Send the cursor position.
sync.debounce   Milliseconds to wait for the cursor to settle.
autosave        Write tracked buffers automatically.
notify          Show messages with |vim.notify()|.
open            `function(path)` that replaces how the viewer is launched.

==============================================================================
4. LUA API                                                         *markedit-api*

`require("markedit").setup({opts})`   Configure the plugin.
`require("markedit").open()`          Same as |:MarkEditOpen|.
`require("markedit").close()`         Same as |:MarkEditClose|.
`require("markedit").toggle()`        Same as |:MarkEditToggle|.
`require("markedit").status()`        Table with `running`, `port`, `tracked`
                                      and `clients`.

==============================================================================
5. TROUBLESHOOTING                                      *markedit-troubleshooting*

- |:MarkEditStatus| shows `connected viewers: 0`: the extension is not loaded
  or cannot reach the port. Restart MarkEdit after installing it.
- "could not start the bridge": every port of the range is in use. Close some
  Neovim, or change `port` or `port_count` here and in the extension settings.
- MarkEdit does not follow the second Neovim: update the extension, an older
  one only knows the first port.
- "rejected request from origin" in |:MarkEditLog|: the sender reports an
  http(s) origin that is not allowed. Add the printed value to
  `allowed_origins` (it replaces the default list).
